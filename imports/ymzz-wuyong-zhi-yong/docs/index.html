🌀 什麼是「無用之用」

老子《道德經》：「三十輻共一轂，當其無，有車之用。」把這個比喻套進 Agent：Agent 本體是空的轂，skill 是可換的輻。 正因為 Agent 本體不寫死任何業務技能，它才能隨時換上不同的 skill。

這個倉庫不內置任何業務 skill，只內置「找 skill、管 skill 池」的能力。Skill 池不是手寫清單——它由 skills.sh 排行榜（按調用量由上往下取）＋ 本地製作歷史 動態算出。

本地優先 跨對話索引 安全閘 零遙測 Python ≥3.11 零第三方依賴 DSH 插件

🎯 核心行為

1. 雙通道即時判別

同時觀察「用戶說了什麼」與「模型思考（Thinking/Reasoning Trace）」，兩者任一暗示需要外部能力就行動。輸出完整 Decision JSON。

2. 本地優先路由

嚴格按順序：local → pool → online → none。未命中時誠實回報缺口，並協助起草 SKILL.md。

3. 動態技能池

從 skills.sh 抓取排行榜，安裝量嚴格大於 1,000,000 才入池；過濾副本；連續 2 次低於門檻才標記；本地自製永不自動刪除。

4. 安全閘（不可省略）

第三方 SKILL.md 與附帶腳本視為不可信資料；審計 fail 拒絕入池，warn 標記 review，不自動執行腳本。

🚀 快速開始

# 1. Clone
git clone https://github.com/Ya-MiC/ymzz-wuyong-zhi-yong.git
cd ymzz-wuyong-zhi-yong

# 2. 初始化（安裝核心源 find-skills，首次監控）
python -m wuyong bootstrap

# 3. 驗證環境
python -m wuyong doctor

# 4. 單條決策（預設 dry-run，不動磁碟）
python -m wuyong hint --text "幫我找一個現成的 react 技能" --mode advise --dry-run

# 5. 技能池同步
python -m wuyong monitor --once

CLI 指令

  • doctor — 檢查環境與核心 skill
  • bootstrap — 初始化 + 安裝 find-skills
  • monitor --once / --daemon — 技能池同步
  • pool list / show / sync — 查看與同步池
  • local harvest / register / list / search — 本地索引
  • hint — 產出 Decision JSON
  • watch — 從 stdin 逐條輸出 Decision
  • uninstall — 乾淨卸載

DSH 插件

以 dsh-bundle/wuyong 安裝進 DSH，暴露 wuyong.doctor、wuyong.hint、wuyong.pool.*、wuyong.local.* 六個工具，作為本地 MCP 常駐子代理（高權限技能）使用。

查看安裝方式

📦 安裝四個核心 skill（底層認可）

npx skills add https://github.com/vercel-labs/skills --skill find-skills --yes --copy --json
npx skills add https://github.com/vercel-labs/agent-browser --skill agent-browser --yes --copy --json
npx skills add https://github.com/mattpocock/skills --skill grill-me --yes --copy --json
npx skills add https://github.com/heygen-com/hyperframes --skill hyperframes-cli --yes --copy --json

# 收錄進本地索引（跨對話可重用）
python -m wuyong local harvest

這四個已鎖進 config/core-skills.lock.json（required: true），bootstrap 會冪等安裝，失敗標記 degraded 並自動重試，不假裝成功。
