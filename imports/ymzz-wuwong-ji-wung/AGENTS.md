# 晏銘湛箴_無無即無 (wuwong-ji-wung) — AI 代理協作規範

本倉庫為晏銘湛箴「無無即無」本地優先知識記憶與子智能體協作平台。任何 AI 代理在本倉庫工作前請先閱讀本文件。

## 顯示名稱
晏銘湛箴_無無即無

## 技術棧
Tauri 2 + Rust + Vue 3 + TypeScript。本地優先，離線可用，預設不連網。

## 核心約束（不可更改）
- 預設不連網，不收集資料，不改註冊表，乾淨卸載
- 軟件 MIT 授權；依賴、字體、圖標皆可商用
- 原色票不得更動（溫潤設計系統四套色票）
- 觸控熱區 ≥ 44px，連續熱區無死區
- 不全量採集用戶本地數據，只留使用者主動確認片段

## 工作方式
- 分階段交付，每階段結束等使用者確認
- 使用繁體中文回覆，術語首次出現附英文
- 事實標註 [已驗證]/[二手]/[未驗證]，附來源與日期
- 不編造網址、版本、授權、數字

## 子智能體協作
本系統支援三個會話的子智能體互相直接接觸與梳理：
1. 當前會話
2. session-1420479c-b568-4b48-9c9a-266ad85c6e87
3. session-2ae8976d-65a8-46f8-b00b-ba098ee9fd8b

子智能體學習之前人類用戶說過的、以及 codex/cc 之間學過的東西，全部應能互相直接接觸和梳理清楚。

## 開發指令
```bash
# 安裝依賴
npm install

# 開發模式（前端 Vite + Tauri）
npm run dev

# 建置生產版本
npm run build

# Tauri 打包
npm run tauri build
```

- 研究產出 → docs/
- 程式碼 → src/（前端 Vue）與 src-tauri/（後端 Rust）
- 設計 tokens → design/（引用溫潤設計系統）
