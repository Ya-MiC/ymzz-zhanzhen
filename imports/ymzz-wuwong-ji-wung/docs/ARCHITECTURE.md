# 無無即無 — 架構概要（首版）

本地優先知識記憶與子智能體協作平台。Tauri 2 + Rust + Vue 3 + TypeScript。

## 分層

```
┌─────────────────────────────────────┐
│  Vue 3 + TypeScript 前端 (WebView)   │  溫潤設計系統主題切換
├─────────────────────────────────────┤
│  Tauri 2 IPC / Commands             │  前端與 Rust 後端通訊
├─────────────────────────────────────┤
│  Rust 後端 (Tauri)                  │  本地 SQLite 儲存、全文檢索
├─────────────────────────────────────┤
│  SQLite (本地檔案)                  │  對話片段、知識節點、會話索引
└─────────────────────────────────────┘
```

## 核心模組

| 模組 | 職責 | 語言 |
|------|------|------|
| 前端 | 知識節點編輯、會話切換、主題切換、全文檢索 UI | Vue 3 + TS |
| IPC 層 | 前端與後端命令與型別共享 | Tauri 2 |
| 儲存層 | SQLite 本地儲存、節點 CRUD、跨會話索引 | Rust + rusqlite |
| 檢索層 | 全文檢索（FTS5）、標籤過濾、跨會話關聯查詢 | Rust |
| 主題層 | 溫潤設計系統四套色票切換 | CSS 變數 |
